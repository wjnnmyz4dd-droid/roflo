# The IANA timezone database. Not a reader, and here for a reason
# Windows CI found: Windows ships no tz database at all, so
# `ZoneInfo("America/New_York")` fails and DeskPilot falls back to
# UTC -- visibly, saying so in the summary, which is the right
# behaviour and still means the owner's 06:50 briefing arrives at
# some other hour. zoneinfo picks this package up automatically when
# the system has no database, so shipping it is the whole fix.
# tzdata-2026.5-py2.py3-none-any.whl  [Apache-2.0]
