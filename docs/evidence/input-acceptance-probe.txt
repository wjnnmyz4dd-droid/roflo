Realistic client inputs fed to the existing workers from a scratch
directory outside the repository. Read-only: no production code was
modified and nothing was installed.

Two rows below are probe artifacts rather than capability gaps, and
are corrected in the report: "comma decimal" refused on a column-name
mismatch I introduced, and "plain text (supported)" refused because
the probe passed a requirement that did not match it. Re-run cleanly,
.txt is read and EU decimals pass through untouched when nothing
computes on them.
